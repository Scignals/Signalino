# Signalino Suite 0.9.0 Preview

This is the first public preview of Signalino Suite. It is intended for
evaluation with Signalino development hardware and is not yet a signed
production release.

## Included

- exclusive USB, Bluetooth Classic and BLE transport selection where supported;
- Signalino connection and LSL status;
- live EEG viewer with stream selection;
- impedance check window;
- EEG, sensor and marker recording to CSV;
- bounded diagnostic log and device commands;
- support for stable Signalino device identities and multiple LSL streams.

## Downloads

### macOS Apple Silicon

Download `Signalino-Suite-0.9.0-macOS-arm64-preview.dmg`, open it and drag
Signalino Suite to Applications. It requires macOS 13 or later.

The preview is ad-hoc signed but not Apple-notarized. macOS may require using
Open from the application's context menu or approving it under Privacy &
Security. Do not disable Gatekeeper globally.

USB, paired Bluetooth Classic and native BLE are included.

### Windows x64

Download `Signalino-Suite-0.9.0-Windows-x64-preview.zip`, extract the complete
folder and run `SignalinoSuite.exe`. The .NET runtime and LSL library are
included.

The preview is not code-signed, so Microsoft Defender SmartScreen may request
confirmation. USB and paired Bluetooth Classic are included. Native BLE is not
yet available in the Windows Suite.

### Debian/Ubuntu x86_64

Download `signalino-suite_0.9.0_amd64.deb` and install it with:

```bash
sudo apt install ./signalino-suite_0.9.0_amd64.deb
```

The package targets Ubuntu 22.04 or a compatible Debian-based distribution.
USB, paired Bluetooth Classic and BlueZ BLE are included. Some desktop tray
features require the recommended AppIndicator packages.

## Validation

The shared core, frame decoder and live LSL reader contracts pass on macOS,
Windows and Ubuntu in automated builds. The macOS disk image was also mounted,
signature-checked and launched on Apple Silicon before publication.

## Known limitations

- preview packages are not commercially code-signed or notarized;
- macOS Intel and Linux ARM packages are not included;
- Windows native BLE is pending;
- firmware installation and application updates are not yet automated;
- impedance values on prototype hardware still require hardware calibration.

Verify downloaded files against `SHA256SUMS.txt` when transferring them through
an untrusted intermediary.
