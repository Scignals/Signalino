# Signalino Suite 0.11.0 Preview

Evaluation release for macOS Apple Silicon, Windows x64 and Ubuntu/Debian amd64.
Not clinical validation or a commercially signed/notarized release.

## Changes

- Unified USB / Bluetooth Classic / Bluetooth LE selection, automatic discovery
  on startup and transport changes, and idle USB hotplug refresh. Connect remains
  explicit; a sole result is selected, multiple results require a choice.
- Confirmed amplifier names beside USB ports, without trusting historical names
  for ports that may have been reassigned.
- Diagnostics > Device Simulation (S3): use the S3's synthetic source without
  an ADS1299 or an external emulator. Disconnect before toggling. The selection
  is remembered and the source is checked before streaming. Requires compatible
  S4 firmware; firmware is not installed by this release. The computer mock and
  EDF replay remain separate.
- Direct recording-folder access and an active recording line showing the final
  CSV filename and elapsed seconds. Stop freezes the counter during EDF export.
- Connection/recording safety and impedance lifecycle fixes; Windows BLE receiver
  improvements accumulated since 0.10.0.

## Install

- Mac: quit Suite, open the arm64 DMG and replace the app in Applications.
- Windows: quit Suite, including its tray icon, extract the entire x64 ZIP to a
  new folder and run SignalinoSuite.exe. The .NET runtime is included.
- Linux: `sudo apt install ./signalino-suite_0.11.0_amd64.deb`, then launch
  `signalino_linux_suite` or use the desktop launcher.

Existing user settings are retained. Back them up before upgrading. Packages are
not commercially code-signed/notarized. Use the normal OS approval process; do
not disable system-wide security protections.

## Validation and limitations

Release artifacts are published only after the three-platform desktop workflow
passes builds, shared tests, LSL/EDF integration and packaged-layout smoke tests.
BUILD_INFO.json identifies the exact revision and workflow run; SHA256SUMS.txt
provides download integrity checks. Third-party notices accompany the packages.

Local Mac USB tests confirmed S3 synthetic streaming and recording controls.
The user reports successful operation on other desktops; this is not exhaustive
physical-radio acceptance. Check USB/Classic/BLE on the intended computer and
adapter. Long-duration acquisition and clinical suitability are not established.
Multi-amplifier support and recovery behavior are not identical on all platforms.

The optional computer mock needs Python 3; EDF replay additionally needs numpy
and pyedflib. Windows hardware acquisition does not need Python. Android,
HepatoSense and firmware are separate releases and are not updated here.
